01

베이비노트

5개월 딸을 키우며 직접 만든 육아 기록 앱

아이폰 출시 · 갤럭시 테스터 모집

문제

  • 기존 육아기록 앱의 불편함
  • 깨시 추적, 수유 추적이 번거로움
  • 음성 명령 미지원
  • 대시보드가 한눈에 안 들어옴

만든 것

  • 깨시·수유 추적, 원형 하루 타임라인
  • Siri 음성 명령으로 기록
  • 홈 화면 위젯 대시보드
  • 성장 그래프, AI에게 물어볼 자료 만들기

결과

  • 우리 부부의 육아 기록 품질 향상

헬창노트

애플워치가 횟수를 세 주는 운동 기록 앱

아이폰 출시 · 갤럭시 워치 테스터 모집

핵심 기능

  • 워치의 자이로센서로 운동 횟수 자동 측정
  • 세트·휴식 타이머, 심박 표시
  • 근육별 운동량과 종목별 성장 그래프

대상

  • 웨이트 트레이닝 기록을 진심으로 하는 사람
03

Daily English with Soya

회화 강사인 아내를 위한 1:1 말하기 숙제 앱

아내 업무 자동화

문제

  • 숙제 검사를 카톡 음성으로 주고받음

기능

  • 녹음 숙제 제출, 앱 설치 없이 홈 화면에서 바로
  • Voice to text: 학생 음성을 자동으로 스크립트화
  • 틀린 그 초에 피드백을 핀으로 남김, 문법 오류 표시
  • 자주 틀리는 습관을 해시태그로 자동 정리

결과

  • 학생의 실력 개선을 그래프로 확인
